# 演出直接采集与持久化索引 v1

日期：2026-11-15。基于 [11 月 14 日实测调研](../research/event-crawling-plan-2026-11-14.md) 实施。

## 已实现范围

- 北京文旅：按艺人查询公示、发现详情及 PDF，用 PDFBox 提取前三页文字层，再按批文语句边界提取演出范围、场馆、名称和许可编号。
- 广州文旅：发现近期“行政许可事项（营业性演出）”文章，按表头提取各行，排除机构资质公示；分页只跟随实际页面链接，不猜测 URL。
- 大麦：一次匿名查询并检测验证码、403/429 和异常结构；不绕过限制，尚未提供经过验证的大麦演出列表解析能力。
- 全国涉外查询动态页面及其他省市暂未适配；扫描预算、未启用来源和受阻来源会反映在覆盖说明中。

## 运行链路

`EventCrawlIndex` 后台线程每分钟选择一位到期艺人，按来源独立刷新；每个艺人 / 来源默认 6 小时内不重复采集。初始艺人为薛之谦、周杰伦、林俊杰，后续查询会登记其他艺人，默认最多 32 位。

查询通过 `EventSearchService` 读取索引，并与原有搜索结果合并。查询线程不等待外站采集；首次登记返回 `INITIALIZING`，超过登记容量返回 `WATCH_LIMIT`。一轮采集可持续数十秒，新艺人可能等待多个调度周期。

来源白名单在查询和后台刷新前重新读取。删除来源或改变层级后，已有索引也不会被返回；白名单服务不可用时维持原有覆盖未知处理。

## 数据语义

- 保存公开演出字段及来源链接，不保存 PDF 原文、完整演员表、证件号、Cookie、安全令牌或密钥。
- 批文受理日期、许可日期和文章发布日期不作为演出日期。
- 日期范围仅记录在 `approvedNote` / `dateExpression` 中；不展开成每天一场。只有明确单日的许可才填充 `eventDate`，仍是 GOV 审批信息，`canBuyTicket=false`。
- 相同艺人、城市、已知场馆、名称和许可范围的直接采集批文可以合并证据；缺少这些条件时保留不同候选，不强行认定同一演出。
- 取消 / 撤销记录保留冲突标记，合并后不丢失。批文 PDF 链接通过 `approvedUrl` 保留。
- 已按站点规则解析的公示页替代同 URL 的搜索摘要推断，防止摘要把审批区间展开成每日场次。
- 采集失败或部分分页未扫描不会删除旧记录；默认 24 小时未重新核实的记录标为过期。距今超过 60 天的已结束许可在更新时清理。

## 存储与容量

本版不修改数据库结构，采用 MCP 独立持久化 JSON 索引。服务器将 release 下 `event-crawl-data/` 挂载到 `/app/event-crawl-data`，因此容器重启、重建不会清空数据。此目录属于运行数据，不提交 Git。

索引采用临时文件加原子替换，损坏文件标记 `STORE_READ_FAILED` 并保留原文件，不自动覆盖；写入失败标记 `STORE_WRITE_FAILED`。索引版本为 1，上限 8 MB；每个艺人每来源最多 500 条。该实现面向单个 MCP 实例，扩多实例或扩大规模时应迁移到数据库及共享任务协调。

## 配置

前缀：`starlineagent.event-crawl`。本地默认关闭；服务器 Compose 显式启用。

| 属性 | 默认值 | 含义 |
| --- | --- | --- |
| enabled | false | 是否登记、读取索引和启动采集线程 |
| damai-enabled | false | 是否执行大麦匿名探测 |
| directory | ./event-crawl-data | 持久化目录 |
| artists | 薛之谦、周杰伦、林俊杰 | 初始艺人 |
| refresh-millis | 21600000 | 每艺人每来源的刷新 / 失败冷却时间，最少一分钟 |
| stale-millis | 86400000 | 记录过期阈值，最少一分钟 |
| max-artists | 32 | 登记艺人上限，硬上限 128 |
| max-list-pages | 2 | 单来源列表页上限，硬上限 3 |
| max-details | 6 | 北京详情尝试次数上限，硬上限 12，失败也消耗预算 |
| max-notices | 4 | 广州公示文章上限，硬上限 12 |

每来源另有限制：最多 24 个请求、90 秒总预算；单请求 4 秒连接 / 读取超时和 8 秒读取截止；响应最大 5 MB。固定 HTTPS 主机白名单，DNS 公网校验后绑定实际连接地址，校验 TLS 主机名，不跟随重定向，相邻请求间隔至少 1 秒。403、429、验证码和访问边界错误停止当前来源，不在本轮重试。

PDF 无文字层返回 `OCR_REQUIRED`，本版未实现 OCR。损坏附件、解析结构变化单独记录，不生成猜测数据。PDF 超过 50 页拒绝，只提取前三页。

## 接口与排障

- 原 `search_artist_events` 的请求参数保持不变。
- 新增 `coverage.crawlSources`、`coverage.crawledCandidates`、`coverage.crawlRevision`；notes 解释采集状态及日期范围。
- 第一页查询在索引更新后生成新快照；已有分页继续读取旧快照，来源白名单变化仍会使游标失效。
- 容器内部状态接口：`GET /internal/event-crawl/status`。MCP 不映射宿主机公网端口，接口只返回运行状态、计数和错误代码。
- 存储异常时先备份目录再处理；禁止直接覆盖损坏原文件。遇验证码检查来源状态，不把空候选解读为没有演出。
