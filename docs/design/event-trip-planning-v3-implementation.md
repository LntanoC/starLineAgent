# 观演出行 v3 实施记录

依据 [v3 方案](event-trip-planning-v3.md)，替换旧单段路线工具和无费用模型；不改变用户现有会话数据。

## 已实现

- `plan_journey`：普通问路，出发/到达时刻二选一；返回起终点解析、候选方案、分段时间轴、交通方式、可行性、费用、人均/同行合计、返程和警告。
- `plan_event_journey`：以艺人和城市查官方来源，再选场次、确认场馆与开场、规划去程和返程。最多两个结构化追问。只有日期不能开始路线计算。“上海站”只在巡演 city 槽位归一化；普通起终点保持铁路站含义。
- `search_artist_events`：保留旧字段，新增可空场馆、地址、开场、散场、票档和来源；仅抽取白名单搜索摘录中有明确标签的值。不是网页全文抓取，摘录不足时明确追问。同城同日不同场馆不合并。
- 纯计算：严格分单位金额、区间、按人/同行/每车分摊；未知金额必须为 null。反向到场计算、跨天铁路时刻、进站缓冲、候车、接驳、首末班边界与不可行判断。错过班次时不提供虚假的到达时刻。
- 直辖市兼容：真实高德可能把省/市同名的直辖市城市定位点标为省级，按返回字段归一为业务市级，保留原坐标、低精度及“不是门到门”提示。大群体的单车容量/车辆数量未知时不推荐为确定可行。
- 候选：高德公交/铁路组合、自驾、打车参考价和3公里内步行；解析所有返回方案，按班次/线路去重并选取展示候选。逆向先查耗时再重查对应出发窗口，保留真实返回班次；不会拿倒推时刻当真实车次。
- 返程：跨城观演默认开启，同城默认关闭；散场未知时返程、费用和末班车显式未知。已知散场加20分钟疏散缓冲后独立查询，不复制去程票价。赶不上时提示其他交通、次日返程或住宿，住宿不计价。
- 推荐：先考虑可行性，再考虑完整费用的预算匹配、耗时、接近耗时下的换乘数及费用完整度。无全程可确认方案时 recommendedOptionId 为 null；未知价不参与最省比较。
- 可靠性：共享 HTTP 超时、幂等GET一次重试、24小时地点缓存、10分钟路线缓存、5分钟事件缓存、API Key 进程并发上限、用户工具并发上限、5次故障后30秒熔断、并行候选与8/12秒规划预算。日志仅记端点、耗时、状态、缓存和缺口数量。
- 前端：兼容解析 v3 卡片，展示偏好筛选、时间轴、费用范围/来源、可行性、返程与追问；未知项不会渲染成0，旧历史工具返回继续走原始文本展示。

## 对原方案的必要澄清

1. 正文阈值优先于示例：slack=10 属 TIGHT，15及以上才为 FEASIBLE；无班次的公共交通可行性为 UNKNOWN。
2. 返程独立查询优先于示例：未验证返程价格时标未知，不照抄去程票价。
3. POI 只能解析已知场馆或用户给出的别名，不能证明某艺人在某馆举办；未从事件来源取得场馆时不会以“艺人+城市”猜一个 POI。
4. `minTotalMinor/maxTotalMinor/knownSubtotalMinor` 统一指同行合计；增加 `perPersonMinMinor/perPersonMaxMinor` 避免前端再按范围混算。自驾按一车共乘，明确提醒容量/车型待确认。
5. 请求的 origin 由 Agent 从已确认对话/画像/长期记忆带入；隔离的 MCP 服务不直接访问用户记忆库。未带入时返回澄清，不声称已经检索了记忆。

## 配置与更新

沿用 `AMAP_API_KEY` 和 `YUANBAO_SEARCH_API_KEY`。`starlineagent.trip-planning` 可配置 `default-arrival-buffer-minutes`（30）、`rail-station-buffer-minutes`（30）、`crowd-buffer-minutes`（20）、`max-concurrent-requests`（4）、`litres-per100km`（8）和 `yuan-per-litre`（8）。油费参数是显式估算配置，不是实时油价；停车费未知时不补默认价格。

运行 `node scripts/sync-journey-metadata.mjs` 同步工具说明、初始化模板校验和及 `261104_journey_v3.sql`。生产只执行该增量迁移：停用旧工具、注册新工具、更新出行手册、替换内置提示词的旧工具名并追加 v3 规则；不执行清库初始化。重启 MCP/API 刷新 schema；只清理提示词和技能两个精确 Redis 缓存键。

新增工具尚无语义向量时沿用现有关键词召回，加载技能后两个工具受技能保护可见；管理员可在 MCP 工具管理页重建向量。迁移不会伪造向量或重新初始化业务数据。

## 验证与边界

MCP 全模块测试、Java→TypeScript 契约、初始化模板离线校验及桌面/手机卡片浏览器验证均执行；详见当日变更记录。黄金集是确定性编排测试，不等同于在线模型 ≥90% 通过率；真实源覆盖和 P95 尚未做批量评测。

没有接入12306/商业铁路票务、航班/大巴专用时刻、余票、订票、酒店/餐饮价格或多日旅游。打车采用高德返回参考价；未配置各城市计价表时不臆造起步价。票价、散场、首末班和事件摘录缺失时保留 UNKNOWN/追问。`revise_journey` 属后期，当前使用同一工具带更新参数重算。

高德字段依据：[路径规划](https://developer.amap.com/api/webservice/guide/api/direction)、[POI搜索](https://developer.amap.com/api/webservice/guide/api/search/)。
