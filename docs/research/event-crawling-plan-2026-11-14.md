# 文旅与大麦演出信息采集调研

调研日期：2026-11-14（北京时间）。本轮完成代表性站点结构检查及小规模采集验证，不代表全国站点已适配或历史数据已采全。

## 1. 北京：从列表追踪到 PDF

入口：<https://banshi.whlyj.beijing.gov.cn/cms/web/whj/index.jsp>

已观察参数：`name=薛之谦`、`curPage=1`；列表中详情为 `content.jsp?id=...`，详情内附件形如 `/publish/7852144022835279.pdf`。翻页必须按页面实际状态停止；本次检索首屏的“上一页”和“下一页”都指向第一页，不能无条件递增或跟随链接形成循环。

实施步骤：

1. 首次按艺人关键词发现历史公示；长期任务另扫描新增许可列表，避免标题未包含主要艺人时漏项。
2. 对列表链接去重，进入详情，提取完整标题、发布日期、正文与附件 URL。列表标题会截断，不用它生成最终演出标题。
3. PDF 先提取文字层；有效文档没有文字层时进入 OCR 队列。下载不完整、解析错误与扫描件须区分，不能把所有错误交给 OCR。
4. 从批文正文解析演出名称、许可编号、场次、日期地点；保留字段对应的证据。人员清单中的证件号码等不进入演出索引或日志。
5. “增加演员”“变更”“增加场次”等作为同一演出的不同许可记录保存，不能把 6 条批文直接算成 6 场演出。

本轮 pypdf 成功读取 `7852144022835279.pdf`：1 页，有文字层并包含薛之谦；`7127440160823031.pdf` 连续两次验证出现 `PdfStreamError: Stream has ended unexpectedly`。脚本保留附件地址和异常，不伪造演出日期。

## 2. 广州：按表头解析，不用全文正则拆日期

栏目入口：<https://wglj.gz.gov.cn/xxgk/bmwj/ywxx/wgl/>

已确认列表包含当月“行政许可事项（营业性演出）”文章，也混有“演出经纪机构《营业性演出许可证》”公示。后者是机构资质信息，不能当作演出项目。

验证样例：<https://wglj.gz.gov.cn/xxgk/bmwj/ywxx/wgl/content/post_10729254.html>

样例成功提取：

```json
{
  "artist": "薛之谦",
  "approvalNo": "440100522026000273",
  "approvalDate": "2026-03-10",
  "approvalType": "演出活动非内地变更",
  "venue": "广州天河体育中心体育场",
  "approvedDateRange": ["2026-03-20", "2026-04-05"],
  "sessions": null,
  "canBuyTicket": null
}
```

这是字段归一化示意；脚本实际保留原始表头和值。审批区间不自动展开为每天一场，也不代表当前可以买票。标题里的公示周期、文章发布日期、许可日期和演出日期是四种不同时间。

长期采集需扫描栏目分页，按文章 URL / 发布日期做增量，回扫近期已读文章以发现修改；按表头定位单元格，检测合并单元格及列数变化，结构不符时进入人工检查，不能悄悄错位写库。

## 3. 全国查询：先验证浏览器查询结果

入口：<https://zwfw.mct.gov.cn/zwfw/wycx/qgswyyxychd/>

公开页面脚本显示：

- 获取密钥路径表达式：`urlIp + "/getsm4key"`。
- 列表请求路径表达式：`urlIp + "/swychd"`。
- 请求数据由页面 SM4 方法处理；这些不是已经验证可直接使用的开放 API。
- 查询字段：`pageSize`、`pageNum`、`performanceName`、`performancePlace1`、`performingBeginTime`、`performingEndTime`。
- 返回读取逻辑使用 `list` 和 `pagination`；详情链接形如 `./xq/?id=...`。

建议下一阶段先用浏览器按正常交互输入艺人、地区和日期，确认能显示真实结果，再读取渲染后的表格和详情。不要把 HTML 中注释里的演出样例当成结果。本轮未执行密钥和列表请求；一次使用 Python 默认请求头的后续请求返回 403，不能据此断言所有浏览器均不可用。

该入口名称明确是“全国涉外营业性演出活动”，不承诺覆盖所有国内演出；仍需各地许可公示作补充。

## 4. 大麦：已找到页面调用路径，仍有实际阻断

搜索页：<https://search.damai.cn/search.htm?keyword=%E8%96%9B%E4%B9%8B%E8%B0%A6>

页面引用的公开脚本：<https://g.alicdn.com/damai/vue-pc/0.0.85/search/search.js>

脚本中实际调用 `//search.damai.cn/searchajax.html`，能观察到 `currPage` 分页与 `totalPage` 使用逻辑。当前验证请求使用 `keyword`、`currPage`、`pageSize`；尚未验证每个参数是否生效、返回结构是否满足项目需要。

本轮再次得到 HTML 验证码拦截，状态记录为 `BLOCKED_CHALLENGE`，不输出空数组。能够下载搜索页面及 JS 不能证明可以读取演出结果。

后续可做一次正常浏览器交互验证；若可见真实结果，再核对标题、城市、场馆、场次、价格和购票链接。Playwright 可处理网页渲染，但不能作为绕过验证码或取得数据许可的保证。遇到登录、验证码和权限限制时保留失败原因，转向授权 API、合作来源或官方跳转链接。使用范围参考[大麦用户服务协议](https://help.damai.cn/helpPage.htm?pageId=38)。

## 5. 接入 StarLineAgent

现有 `EventSearchService`、`EventPageExtractor`、`EventMerger` 和来源证据模型可复用；现有 `EventPageReader` 主要读取 HTML / JSON-LD，不执行网页 JS，也不解析 PDF，无法直接承担以上所有站点。

推荐流程：

```text
来源注册表（站点、栏目、地区、适配器、启用状态）
  → 定时采集（按站点限速、超时、有限重试）
  → 列表发现 / 详情与附件提取
  → 原始证据保存 / 字段归一化
  → 许可变更关联 / 演出实体与具体场次合并
  → 持久化索引
  → EventSearchService 合并数据库结果与现有搜索结果
  → search_artist_events 返回数据、来源和覆盖限制
```

- 站点适配器共享 HTTP、编码、重试、附件处理，分别实现列表分页与字段解析，不能用一个通用选择器覆盖全国。
- 推荐先完成北京和广州两种模板，再扩省市；湖南行政许可列表可作为候选：<https://whhlyt.hunan.gov.cn/whhlyt/xxgk2019/xxgkml/xzxk/>（仅发现入口，未本地实测）。上海、江苏、浙江本轮未完成采集适配。
- 采集以页面声明的访问规则和许可范围为准。建议起始每域并发 1、间隔至少 1 秒；403/429/验证码停止本轮来源采集，429 遵循 Retry-After；这是初始工程配置，不是网站授权或稳定性保证。
- 以来源文档 ID / URL + 内容哈希检测更新，以发证机关 + 许可编号关联批文，再按艺人、演出名称、城市、场馆和明确场次关联演出。没有足够证据时保留候选，不能仅凭艺人和城市强行合并。
- 对每个字段保留原文、sourceUrl、fetchedAt、publishedAt、parserVersion；缺失值为 null，不让模型补造场馆和开场时间。
- 审批状态与售票状态分别存储；`APPROVED` 不推出 `ON_SALE`。采集失败不清空已存结果，保留最后成功更新时间并标记过期。
- 网页和 PDF 内容是外部数据，不作为 Agent 指令；附件 URL、重定向地址及 DNS 仍须经过公开地址与域名校验。

## 6. 运行原型与验收边界

```powershell
python scripts/probe-event-crawlers.py --out docs/research/event-crawl-sample-2026-11-14.json
# 若 Python 环境安装了 pypdf，可额外检查 PDF 文字层：
python scripts/probe-event-crawlers.py --pdf --out docs/research/event-crawl-sample-2026-11-14.json
```

脚本使用固定 HTTPS 域名白名单，不自动跟随重定向；请求间隔不少于 0.8 秒、超时 15 秒、单响应最多 5 MB；北京最多检查首屏 2 条详情及附件，广州固定历史样例，大麦请求一次。它是结构可行性验证工具，没有任务调度、完整分页、OCR、数据库写入或生产采集能力。普通 Python 可运行 HTML 部分；本轮 PDF 检查使用 Codex 自带 Python 和 pypdf，未安装项目依赖。

验证：Python AST 检查和针对表格 / 链接提取的离线断言通过；最终脚本真实请求 7 次，北京部分成功、广州样例成功、大麦拦截。保留失败状态，不以进程退出码 0 代表所有来源成功。清城 TLS 异常及全国查询页 403 由独立调研请求观察，未隐藏为采集成功。

本轮均从本地发起请求，未操作项目服务器、部署采集任务或修改应用运行代码。
