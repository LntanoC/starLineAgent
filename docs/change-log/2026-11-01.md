# 2026-11-01 变更记录

## 长任务阶段级 Tool RAG 刷新

将 MCP 工具目录加载改为“Agent 内部保留当前已授权、可分发的工具集合，模型每轮只看到当前子目标召回的 schema”。新增 `search_tools` 阶段切换工具：长任务切换到新阶段时更新本次运行的子目标，下一轮重新召回工具；保留技能手册解锁规则和 MCP 代理执行遮蔽，召回异常时闭锁到内置工具与常驻工具。以“南京出发去上海、先查演出再规划出行”为例，活动阶段完成后 Agent 可切换到跨城路线阶段，而不用把所有 MCP schema 持续塞进提示词。
