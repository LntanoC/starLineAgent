# 项目变更记录

## 2026-10-22：星序活动信息与邮箱提醒首个业务切片

本记录对应本地 Git 工作区当前未提交的星序 MVP 变更。以下逐项说明文件、类/方法和职责。

### 后端业务模块

- starline/pom.xml：新增 Maven 子模块 starline，依赖 system 与 Spring Mail，作为星序活动信息和提醒业务域。
- starline/src/main/java/com/nageoffer/ai/starlineagent/starline/config/StarlinePropertiesConfiguration.java：StarlinePropertiesConfiguration 启用 StarlineMailProperties 配置绑定，使邮件发件配置可注入。
- starline/src/main/java/com/nageoffer/ai/starlineagent/starline/controller/StarlineEventController.java：StarlineEventController 提供活动提醒 REST API；listMine() 查询当前登录用户的记录，create(request) 创建活动/提醒，cancelReminder(id) 取消提醒。
- starline/src/main/java/com/nageoffer/ai/starlineagent/starline/controller/request/SaveStarlineEventRequest.java：SaveStarlineEventRequest 定义创建请求字段，包括艺人、活动、信息状态、来源确认、开票/提醒时间和邮箱。
- starline/src/main/java/com/nageoffer/ai/starlineagent/starline/controller/vo/StarlineEventVO.java：StarlineEventVO 定义返回前端的活动及提醒状态数据结构。
- starline/src/main/java/com/nageoffer/ai/starlineagent/starline/dao/entity/StarlineEventDO.java：StarlineEventDO 映射数据库表 t_starline_event_reminder，保存用户、活动、来源和提醒投递状态。
- starline/src/main/java/com/nageoffer/ai/starlineagent/starline/dao/mapper/StarlineEventMapper.java：StarlineEventMapper 提供 MyBatis-Plus 数据访问；claimForSending(id, now) 仅在状态仍为 PENDING 时原子改为 SENDING，避免并发重复发送。
- starline/src/main/java/com/nageoffer/ai/starlineagent/starline/service/StarlineEventService.java：StarlineEventService 承担业务校验和状态流转。listMine() 按当前用户筛选并按创建时间倒序查询；create(request) 校验信息状态、必填字段、来源 URL、来源确认、未来开票/提醒时间及邮箱，待公布记录只保存状态、不创建提醒；cancelReminder(id) 仅允许所有者取消仍处于待发送状态的提醒；findDue(now) 查询到期的待提醒记录；claim(id) 抢占发送权；mark(id, status, sentAt) 更新投递结果；私有方法 required、trim、validateUrl、parseTime、toVO 分别负责必填/空白处理、HTTP(S) 来源校验、时间解析和实体到响应对象转换。
- starline/src/main/java/com/nageoffer/ai/starlineagent/starline/service/StarlineMailProperties.java：StarlineMailProperties 绑定 starline.email 配置，提供发件地址。
- starline/src/main/java/com/nageoffer/ai/starlineagent/starline/service/StarlineReminderScheduler.java：StarlineReminderScheduler.dispatchDueReminders() 按配置周期扫描到期记录、抢占发送、投递包含活动和来源链接的邮件，并将状态更新为 SENT 或 FAILED；仅当 starline.email.enabled=true 时启用。

- pom.xml：把 starline 加入根 Maven reactor，参与统一构建。
- bootstrap/pom.xml：让应用启动模块依赖 starline，运行时装载该业务模块。
- bootstrap/src/main/java/com/nageoffer/ai/starlineagent/StarlineApplication.java：在应用的 Mapper 扫描范围增加 com.nageoffer.ai.starlineagent.starline.dao.mapper，让星序 Mapper 被 Spring/MyBatis 注册。
- bootstrap/src/main/resources/application.yaml：通过可选导入加载 starline-application.yaml，未提供邮件配置时应用仍可启动。
- bootstrap/src/main/resources/starline-application.yaml：新增邮件 SMTP 主机、端口、用户名、密码、TLS、发件地址和轮询间隔配置；邮件提醒默认关闭，配置值从环境变量读取。

### Web 前端

- frontend/src/components/agent/AgentSidebar.tsx：AgentSidebar 增加“星序活动提醒”入口，导航至提醒页面。
- frontend/src/router.tsx：注册 /starline/reminders 路由，并放在现有登录校验组件 RequireAuth 内。
