# 2026-11-08 变更记录

## 艺人演出搜索覆盖率与场次解析改造

- 用户授权参考多轮搜索流程改造演出查询；本次只修改本地项目，不执行服务器命令或部署。
- 保留原有 `docs/change-log.md` 和 `docs/change-log/2026-11-01.md` 未提交改动。
- 演出检索改为有查询数量、并发及时间预算的两轮搜索：按演出类型、月份、加场发现线索，再按城市与白名单域名补搜；名单外内容只用于线索，不作为卡片事实。
- 按规范化 URL 去重，保留业务参数；支持部分失败降级、超时取消及结构化覆盖范围和过滤原因统计。
- 新增保守的多日期解析、城市识别和官方 HTML 详情读取；不会把巡演日期跨度直接展开成每天演出，缺少明确年份不猜测。
- 保留白名单与 GOV 许可语义校验；无发布时间标记为时效待核验，日期不明确时不提供购票或提醒依据。
- 演出按日期、城市、场馆/巡演证据合并；未来演出优先，增加 `matchedTotal`、`hasMore`、`nextOffset` 和 `offset` 入参，避免默认 10 条截断没有提示。
- 同步初始化工具描述与校验值，增加离线回归测试及检索配置说明。

### 验证结果

- 执行 `mvn -B -pl mcp-server '-Dtest=*,!*LiveTest' '-Dspotless.skip=true' package`：BUILD SUCCESS。
- MCP 模块 61 项离线测试全部通过，失败 0、异常 0、跳过 0；其中新增演出搜索相关回归 22 项，包含本地 HTTP 协议与既有工具兼容验证。
- 已生成可运行 MCP JAR；构建期间发现并修复日期数组序列化问题，日期与时间现在返回前端可用的 ISO 字符串。
- 搜索两轮合计默认 18 秒，详情读取合计默认 5 秒；第一轮最多使用搜索预算 60%，为官方定向补搜保留时间。默认最多 12 次搜索，可能增加供应商调用成本。
- 初始化工具描述 SHA-256 校验匹配；`git diff --check` 无空白错误。
- 仍有既有平台资源编码（GBK）和 JDK 解析器 API 过时警告，不影响本次构建结果。
- 未调用真实搜索 API、未修改白名单、未执行服务器命令、未部署、未提交 Git。真实召回率未测量，不声称覆盖全部演出。HTML 以外的 PDF/海报/动态登录页与同日多时段仍是已知边界，详见设计说明。
