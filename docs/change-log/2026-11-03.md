# 2026-11-03 变更记录

## ToolRAG 无进展搜索保护

为长任务中的 `search_tools` 增加单次运行级进展跟踪。按规范化 query 和实际召回的动态 MCP 工具集合识别重复搜索；首次无进展返回 `NO_NEW_CANDIDATES` 并允许一次有效改写，再次无进展返回 `EXHAUSTED`。耗尽后由推理中间件隐藏 `search_tools`，成功执行 MCP 工具或加载技能后重开下一阶段的搜索窗口。常驻工具不参与候选指纹，避免固定工具造成误判。
