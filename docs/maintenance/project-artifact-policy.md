# 项目构建产物与本地备份规则

## 本地备份

.local-backups/<任务>/ 只保存无法从当前仓库恢复的修改前源码快照、配置/脚本快照、清单和 SHA-256 校验值。压缩包仅可用于源码快照，并应附带清单。

备份目录禁止保存：

- *.jar、*.tar.gz 等可重建的构建产物
- target/、dist/、node_modules/、运行缓存
- .env、API Key、密码、私钥或其他凭据

## 可重建目录

Maven target/、前端 dist/ 和 Vite deps_temp_* 都由源码与依赖重建。发布前先构建并部署，确认服务正常后可清理本地这些生成目录；node_modules/ 是开发依赖安装目录，不因常规清理而删除。

## 部署上传

大文件优先使用 rsync --partial --inplace 上传到独立暂存目录，完成后校验 SHA-256，再原子替换正式文件并重建受影响容器。--inplace 不得直接用于正在运行的正式 JAR 路径。若本机或服务器缺少 rsync，部署脚本回退到 SCP。不要在传输完成和哈希校验前切换服务。
