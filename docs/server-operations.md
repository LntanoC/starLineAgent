- 每天的操作写入 docs/server-operations/YYYY-MM-DD.md，日期按 Asia/Shanghai（中国标准时间）确定。

- 新日期创建对应文件，并在上表增加入口；总索引不再追加具体命令。
- 密码、API key、令牌、私钥及其他真实敏感值不写入日志。
