# 集团开票信息汇总

## 开票主体识别要点

同一品牌下可能存在总公司与多家分公司，各自是独立的开票主体，抬头、纳税人识别号、纳税资质与银行账号均不相同，不能仅凭品牌名选择。

向供应商或客户提供开票资料前，须用下列三项共同确认唯一主体：

- **所在行政区**：如西湖区、余杭区、滨江区，用于区分同品牌的不同分公司。
- **注册地址中的道路名**：同一行政区内仍可能有多个主体，需比对到具体道路与门牌。
- **纳税资质**：小规模纳税人与一般纳税人属于不同主体，不可互相替代。

三项中若有任意一项对不上，说明选错了主体，须重新核对，不得用相近主体的资料代开。

每个主体的完整开票资料固定包含七项：开票抬头、纳税资质、纳税人识别号、注册地址、电话、开户银行、银行账号。对外提供时七项须齐全，缺项会导致发票作废重开。
