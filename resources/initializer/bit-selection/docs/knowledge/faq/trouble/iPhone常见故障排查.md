# iPhone 常见故障排查

## 排查总原则

**一次只让用户做一步，等到结果再决定下一步。** 一口气抛五条建议，用户做完一堆也不知道该回什么，多轮诊断就塌成一轮。

先问清型号（「设置－通用－关于本机」里的型号名称）和现象发生的时机——是一直如此、某次更新后开始、还是摔过/沾水之后。**摔过或沾水的直接走保修判定，不在排查范围内。**

## 一、无法开机 / 黑屏

### 第一步：确认是不是没电

接上充电器等 30 分钟。电量彻底耗尽的设备插上电后要过一会儿才显示充电画面，不是插上就亮。

### 第二步：强制重启

- 快按一下音量上键，快按一下音量下键，然后按住侧边按钮直到出现 Apple 标志
- **按住不放要持续十秒以上**，很多人松手太早以为无效

### 第三步：换充电线和插头

用另一根线、另一个插头、另一个插座各试一次。线材内部断裂从外观看不出来。

### 第四步：看有没有充电反应

插上后屏幕完全没有任何反应（不亮、不震、电脑也不识别），基本可以判断是硬件问题，走保修或送修。

## 二、充电异常

| 现象 | 先查什么 |
|---|---|
| 完全不充电 | 充电口积灰。用木质牙签轻挑，不要用金属 |
| 时断时续 | 同上，或线材接口松动 |
| 充电很慢 | 充电器功率不够。20W 以上才有快充，电脑 USB 口通常只有 5W |
| 充电时发烫 | 边充边玩会明显发热。取下保护壳、停止使用再观察 |
| 提示「此配件可能不受支持」 | 线材或配件非认证产品，或接口有异物 |
| 无线充电不工作 | 壳太厚、壳里有金属或卡片、对位不准。摘掉壳再试 |

## 三、面容 ID 识别不了

按顺序排查：

1. **清理原深感镜头区域**——屏幕顶部的开孔处有指纹或膜的残胶都会影响
2. **确认没有遮挡**——保护壳边缘、钢化膜开孔位置偏移都可能挡住
3. **看是不是特定场景失败**——强光直射、完全黑暗、戴口罩（未设置戴口罩解锁）都会降低成功率
4. **重设面容 ID**——「设置－面容 ID 与密码」里移除原有设置后重新录入
5. **添加替用外貌**——戴眼镜与不戴眼镜差异大时，这一项很有效

以上都试过仍频繁失败，且「设置－面容 ID 与密码」里出现无法启用的提示，属于硬件问题。

## 四、屏幕问题

| 现象 | 判断 |
|---|---|
| 触控局部无响应 | 先强制重启。仍然如此且未摔过，属于硬件问题 |
| 屏幕有绿线或彩条 | 硬件问题，直接送修 |
| 显示偏色 | 检查是否开启了原彩显示或夜览。在「设置－显示与亮度」里关掉再看 |
| 屏幕不自动旋转 | 控制中心里的竖排方向锁没关 |
| 屏幕自动变暗 | 自动亮度，或设备过热触发保护 |

**摔过之后出现的任何屏幕问题都不属于免费保修**，可能适用 AppleCare+ 的意外损坏保障。

## 五、信号与通话

### 5.1 没有信号

1. 开关一次飞行模式
2. 重启设备
3. 取出 SIM 卡重插（实体卡），或在「设置－蜂窝网络」里检查 eSIM 是否启用
4. 换一个地点试——判断是设备问题还是基站覆盖问题，这一步最有效
5. 重置网络设置（会清掉所有 WiFi 密码）

### 5.2 通话对方听不清

- 检查底部麦克风开孔有没有被壳挡住或积灰
- 换成免提或插耳机通话，判断是主麦克风还是整体问题
- 打开语音备忘录录一段自己听，能直接确认麦克风好不好

## 六、耗电异常

先看「设置－电池」里的用电排行，**多数「耗电快」都能在这里找到具体的应用**。

排除应用因素后再看电池健康度。低于 80% 且在保修期内属于保修范围，见《各品类保修期与保修范围》。

刚更新完系统的一两天耗电偏快是正常的，见《系统更新与版本管理》。

## 七、发热

分清两种情况：

- **使用中发热**：游戏、导航、长时间视频通话、边充边玩，都会明显发热，属正常
- **待机发热**：放着不动也烫，通常是某个应用在后台持续活动。看电池用量排行，或重启观察

**持续高温会触发降频与充电暂停**，屏幕上会出现温度警告。此时停止使用、取下保护壳、放在阴凉处等待，不要用冰箱或风扇急速降温。

## 八、什么时候直接送修

以下情形不用继续排查，直接走保修判定：

- 摔过、进液、挤压之后出现问题
- 屏幕有绿线、彩条、大面积不显示
- 完全不通电且换线换插头无效
- 出现无法消除的硬件提示（如无法启用面容 ID）
- 机身变形、电池鼓包

**电池鼓包要立即停止使用并送修**，不要继续充电。
