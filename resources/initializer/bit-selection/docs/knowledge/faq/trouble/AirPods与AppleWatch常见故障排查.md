# AirPods 与 Apple Watch 常见故障排查

## 排查总原则

一次只让用户做一步。这两类设备没有屏幕或屏幕很小，用户能观察到的现象有限，所以**问清「哪一侧」「什么时候开始」比问现象描述更有用**。

## 第一部分：AirPods

### 一、只有一只有声音

这是最常见的现象，按顺序排查：

1. **两只都放回充电盒，合盖等 15 秒再打开**——多数情况这一步就恢复了
2. **检查无声那只的出声口**——耳垢堵塞会让声音变得极小，听起来像没声音。用干燥软毛刷横向清理，不要往里捅
3. **检查音频平衡**——「设置－辅助功能－音频与视觉」里，左右平衡滑块如果偏向一侧，会造成一只声音很小的错觉。这一项被误改的情况不少
4. **重置 AirPods**——两只放回盒中，合盖，打开盖子，长按盒背按钮约 15 秒直到指示灯闪白，然后重新配对
5. 以上都无效，属于硬件问题

### 二、连不上或连接不稳定

| 现象 | 做法 |
|---|---|
| 设备列表里找不到 | 打开盒盖靠近手机；长按盒背按钮直到灯闪白重新配对 |
| 连上但声音断续 | 周围 2.4GHz 干扰（微波炉、密集 WiFi）；换个环境试 |
| 自动切换到别的设备 | 「设置－蓝牙－AirPods－连接到此 iPhone」改成「上次连接到此 iPhone 时」 |
| 通话时对方听不清 | 麦克风开孔堵塞；或在嘈杂环境下未开启相应模式 |

### 三、充不进电

1. **看充电盒本身有没有电**——把盒子接上电源，打开盖子靠近 iPhone，屏幕上会显示盒子和耳机各自的电量
2. **清理充电触点**——耳机柄底部的金属触点与盒内触点都要清，用干棉签擦
3. **换线换插头**
4. 盒子完全没有充电反应，属于硬件问题

**耳机能充但盒子不能充**，或反过来，是两个不同的部件，报价也不同，见《维修服务报价表》。

### 四、降噪效果变差

先别怀疑硬件。按这个顺序：

1. **换一副新耳塞**——耳塞老化变形是降噪变差最常见的原因，不是耳机坏了
2. **确认耳塞尺寸合适**——尺寸不对导致不密闭，降噪就无从谈起。系统里有耳塞贴合度测试
3. **清理出声口与通气孔**
4. **确认模式**——通透模式和降噪模式是两种，切错了会以为降噪失效

## 第二部分：Apple Watch

### 五、连不上 iPhone

1. **两台都开着蓝牙与 WiFi**，并且靠近
2. **都重启一次**——先重启手表，再重启 iPhone
3. **检查飞行模式**——手表上的飞行模式会单独开启
4. **在 Watch App 里看状态**——顶部会显示已连接或断开
5. 仍然不行就解除配对再重新配对。**解除配对会自动备份到 iPhone**，重配后能恢复

### 六、充不进电

| 现象 | 做法 |
|---|---|
| 完全不充 | 清理手表背面与充电器的接触面，两边都要擦 |
| 充电器吸不住 | 磁吸面有异物，或用的是非认证充电器 |
| 充得很慢 | 快充需要对应的充电器与线材，普通充电器只有常规速度 |
| 显示充电符号但电量不涨 | 温度过高触发保护，等设备降温 |

### 七、健康数据不准或记不上

- **戴的位置**：太松会让心率与血氧测不准。表带要贴合但不勒
- **背面传感器要干净**：汗渍和防晒霜残留会影响读数
- **手腕检测**：「设置－密码－手腕检测」关掉后，部分健康功能不工作
- **纹身与肤色**：部分光学传感器在特定情况下读数会受影响，这是技术限制不是故障

### 八、屏幕与操作

| 现象 | 做法 |
|---|---|
| 屏幕不亮 | 抬腕唤醒可能被关掉；或进入了剧院模式 |
| 触控无反应 | 强制重启：同时按住侧边按钮与数码表冠十秒以上 |
| 屏幕常亮不工作 | 部分型号没有常亮功能；或省电模式下会关闭 |
| 表盘自己变了 | 同一 Apple 账户下的其他手表同步过来的 |

### 九、表带扣不上

**先确认表壳尺寸。** 表带按 40/42 毫米与 44/46/49 毫米分两档，跨档物理上就扣不进去，不是装法问题。表壳尺寸在手表「设置－通用－关于本机」里看。

## 第三部分：共同事项

### 十、什么时候直接送修

- 摔过、进液之后出现问题
- 完全不通电且换线换充电器无效
- 屏幕有裂纹、亮线或大面积不显示
- AirPods 单只彻底无声且重置无效
- 手表背面玻璃有裂纹（会影响传感器与防水）

### 十一、送修前必做

**Apple Watch 要先解除与 iPhone 的配对**，解除时会自动备份。带配对关系的手表进不了维修流程。

**AirPods 不需要额外处理**，但要把两只耳机和充电盒一起送——只送一只无法完整检测。
