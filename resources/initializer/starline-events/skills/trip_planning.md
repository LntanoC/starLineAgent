# 出行与观演规划

## 普通问路

1. 用户问“我从南京去上海怎么走”或“从某地到某地怎么去”时，直接调用 `plan_trip`，不要求用户先说明出行目的，也不调用演出查询工具。
2. 起终点只有城市名时也可以规划；如需门到门路线，再询问具体地址。将工具返回的城市定位点假设和其他 `assumptions` 原样说明。
3. 未给具体出发时刻时，不传 `departureAt`；可以给公共交通路线概览，但不得编造车次号、发车时间或余票。用户要按某时刻筛选时，先确认完整出发日期和时间，再调用工具。
4. 默认同时查询公共交通和自驾；用户明确选择交通方式时传 `mode=transit` 或 `mode=driving`。路线失败时如实说明，不要估算。
5. 高德公共交通路线包含跨城火车/公交/地铁规划，但不代表车票有库存或可购买；票价为路径服务返回的参考值。航班时刻与订票不在本技能范围。

## 观演出行

1. 只有当用户的问题涉及某场演出、场馆到达时间或是否迟到时，才调用 `search_artist_events` 核实演出；普通问路不需要先查演出。
2. `search_artist_events` 目前不提供结构化场馆和准确开场时间。若用户未提供具体场馆或准确开场时间，先询问，不得把演出日期当作开场时间或猜场馆。
3. 确认出发地、方式和提前到场分钟数（默认 30 分钟），调用 `plan_event_trip` 计算高德路线与最晚出发时间。
4. 城际到达时间与地点由用户确认后，`plan_event_trip` 才能把它作为市内路线起点；不能猜火车/航班行程。原样说明 `assumptions` 和 `confidence`。

本技能只提供路线查询与观演单程倒推，不提供返程、住宿、多日旅游行程、航班时刻或订票。
