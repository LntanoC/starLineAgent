## Portainer 密码问题排查（只读）

- 容器启动参数：`/portainer --admin-password-file /tmp/portainer_pw`，数据卷为命名卷 `portainer_data`。
- `/tmp/portainer_pw` 内容为 **bcrypt 哈希**（前缀 `$2y$12$`，60 字节，root:root 644），**不是明文**，无法反推。
- 重置方式：`docker stop portainer` → `docker run --rm -v portainer_data:/data portainer/helper-reset-password` → `docker start portainer`（写操作，未执行，交用户/Codex）。
- 隐患：密码文件放在 `/tmp`，systemd-tmpfiles 重启时可能清理，导致容器重启后找不到文件而启动失败。建议迁到持久目录并收紧为 600。
